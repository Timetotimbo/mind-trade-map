# Atlas of Trading Emotions

An interactive map of trading psychology. Explore emotional triggers, behaviors, and consequences that leak your edge.

**Live site:** https://timetotimbo.github.io/mind-trade-map/

## Run locally

Requires Node.js 18+.

```sh
npm install
npm run dev
```

Then open http://localhost:8080/.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages via `.github/workflows/deploy.yml`.

## Tech

Vite, React, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion.
